Mafia Night Game is a fully open-source, browser-based implementation of the classic Mafia party game. Players join rooms with a 6-digit code, receive secret roles, and play through night phases, voting rounds, and team chats — all orchestrated in real time via Vercel serverless functions and Supabase.

## What's included

<CardGroup cols={3}>
  <Card title="Real-Time Rooms" icon="door-open">
    Create or join a room with a 6-digit code. Up to 20 players per room, polled every 2 seconds.
  </Card>
  <Card title="Role Assignment" icon="masks-theater">
    Mafia, Villager, Doctor, Detective, Silencer — plus unlimited host-defined custom roles.
  </Card>
  <Card title="Night Actions" icon="moon">
    Each special role submits a night action; the narrator resolves outcomes server-side.
  </Card>
  <Card title="Live Voting" icon="check-to-slot">
    Automatic vote tallying with tie-breaking. Eliminates players and checks win conditions.
  </Card>
  <Card title="In-Game Chat" icon="comments">
    Graveyard chat for eliminated players and a private Mafia team chat during night phases.
  </Card>
  <Card title="Casual Mode" icon="person-running">
    Role-only mode strips out app-driven actions so you can run night phases in person.
  </Card>
</CardGroup>

## Get started in three steps

<Steps>
  <Step title="Set up Supabase">
    Create a Supabase project and run `supabase/schema.sql` in the SQL editor to provision the `rooms` and `players` tables with Row-Level Security enabled.
  </Step>
  <Step title="Configure environment variables">
    Copy `.env.example` to `.env.local` and fill in `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, and `CRON_SECRET`. Never prefix server secrets with `VITE_`.
  </Step>
  <Step title="Run locally with Vercel CLI">
    ```bash
    npm ci
    npx vercel dev
    ```
    Open `http://localhost:3000`, create a room, and share the 6-digit code with your players.
  </Step>
</Steps>

<Note>
  `vercel dev` is required — it serves both the Vite frontend and the serverless API routes under `api/` simultaneously. Plain `vite dev` will not work.
</Note>
